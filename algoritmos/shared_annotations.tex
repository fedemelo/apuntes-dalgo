%
% Naming convention: \ann<Concepto>, parametrized by the variable names used in
% the specific listing so the prose stays generic while reading naturally with
% each algorithm's own variable names.

% Overflow-safe midpoint index, e.g. `lo + (hi - lo) // 2`.
% #1: start/left index variable name, #2: end/right index variable name.
\newcommand{\annMitadSinOverflow}[2]{%
  Índice de la mitad del segmento. Alternativa: \inline{(#1+#2) // 2}, pero la suma puede causar overflow.
}
